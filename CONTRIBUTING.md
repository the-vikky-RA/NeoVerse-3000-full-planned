# Contributing to NeoVerse 3000

Thank you for contributing! Please follow these guidelines to keep the project tidy and consistent.

1. Branches & PRs
   - Create topic branches from `main` or `neoverse/init`.
   - Branch name format: `feature/<short-desc>` or `chore/<short-desc>`.
   - Open PRs with a clear description and link to related issues.

2. Coding & Data
   - Use the naming conventions described in README.md.
   - Character data should be added under `Characters/Human/` as JSON files.
   - Keep changes modular; avoid large monolithic commits.

3. Assets
   - Add artwork under `Concept-Art/` with clear filenames.
   - If adding heavy binary assets, consider Git LFS or a separate assets repo.

4. Issues & Labels
   - Use labels from `labels.json` for categorization.

5. Style
   - Write clear commit messages.
   - Keep language consistent and in English for code and assets metadata.

If you need help, open an issue or ping the repo owner.
